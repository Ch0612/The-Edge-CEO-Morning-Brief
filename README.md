# The Edge CEO Morning Brief

Bursa Malaysia investment summaries based on newly released editions of [The Edge CEO Morning Brief](https://ceomorningbrief.theedgemalaysia.com/home/).

## Read the reports

Reports will be listed here after successful publication. No report has been published to this repository yet.

Markdown reports can be read directly in GitHub on a phone. For the coloured HTML version, download the file and open it in a browser; GitHub's file view displays HTML source rather than rendering the report.

## Publication format

- `reports/YYYY-MM-DD.md` — readable summary.
- `reports/YYYY-MM-DD.html` — styled report.
- `workflow-state.json` — publication and issue-tracking state.

The cloud check is scheduled for 11:00am, Monday–Friday, Asia/Kuala_Lumpur. New reports are published after processing finishes and only when a new issue is available. A successful issue is added to the table above after both report files have been saved.

## Report layout

Company stories are consolidated under their industry sector. Every sector uses three columns: Company / investment theme, News, and Investment considerations. The final broader-developments table uses Investment theme, News, and Potential Bursa beneficiaries & considerations. Stock candidates are labelled as inferred or conditional where appropriate. Supplementary notes link to useful further research and data.

This archive contains original summaries and source links. Potential business benefits do not establish an attractive purchase price or guarantee investment returns.
